# 구매 에이전트 — 더현대Hi(더현대닷컴)

공통 규칙([buyer_default.md](buyer_default.md))을 잇는다. 여기에는 이 소싱처만의 차이만 적는다.

## 흐름(2026-10-28)
1. `thehyundai_product_snapshot` — 상품은 원문링크의 `/product/<상품번호>` 로 연다(sources.yaml product_id).
   아래 '구매하기'로 옵션 창을 열고 컬러·사이즈 combobox 에서 주문 옵션('Z1(블랙)/L(100)' = 컬러/사이즈)을 고른 뒤
   '바로구매'로 주문서(`/shop/order`)까지 간다. 주문서 상품 줄의 옵션·수량을 되읽어 다르면 `order_form_mismatch`.
   옵션 창이 없는 상품은 '단일'이다.
2. 결제수단은 **현대백화점카드 하나**(사용자 2026-10-28): 주문서의 '현대백화점카드 즉시할인' 체크 → 결제수단
   '현대백화점 카드' → 등록 카드 **4625**. H.Point 는 쓰지 않는다. `thehyundai_payment_quotes` 가 그 한 줄
   ('현대백화점카드 간편결제')의 결제 금액을 돌려준다.
3. 배송지 — 전부 고객 직배. 고객 이름·주소를 새 배송지로 넣고 전화는 키마스터 신원정보(업무폰).
4. `checkout_enter_thehyundai` — 'N원 결제하기' → 결제창(hdpay.ehyundai.com) → '간편 결제'를 누른 뒤 멈춘다.
   비밀번호(카드 비밀번호 앞 두 자리, 키마스터 site 항목)는 결제 에이전트가 fill_secret 으로 넣는다.
   시험(dryRun)은 결제하기 직전에서 멈춘다.

## 품절
- 옵션 목록에서 '품절' 글자가 붙은 선택지는 고르지 않는다. 상품 화면 위쪽의 일시품절·판매종료 표시는 전체 품절.
