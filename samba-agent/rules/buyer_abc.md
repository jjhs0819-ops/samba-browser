# 구매 에이전트 — ABC마트 · 그랜드스테이지

공통 규칙([buyer_default.md](buyer_default.md))을 잇는다. 여기에는 이 소싱처만의 차이만 적는다.

## 이 소싱처만의 차이
- 그랜드스테이지는 ABC마트와 같은 흐름(스크립트 `abc_*`)을 쓴다.
- **ABC마트는 전부 고객 직배**다(sources.yaml order_type: direct, 사용자 2026-10-22). 고객 이름·주소는
  `abc_set_shipping` 으로 **이번 주문서에만** 새로 넣는다 — 주소록의 기존 항목은 고르지 않는다
  (reuse_saved_shipping: false, 주소록 항목에 남은 옛 고객 번호가 들어가는 것을 막는다).
- 배송 연락처는 고객 번호가 아니라 **업무폰**(키마스터 신원정보 phone, fill_secret)이다.
- 결제는 **네이버페이만**, 네이버페이 결제창 안 카드는 **넥슨 현대카드 고정**(naverpay_cards). 결제창에 그 카드가
  없거나 되읽은 선택이 다르면 결제하지 않고 needs_human(card_missing).
- 원가 = 실제 결제 금액(paid_is_cost) — 카드 청구할인 계수·적립 예정을 반영하지 않는다.
- 그랜드스테이지는 원작자 설정 그대로 **까대기(사무실 수령)** 다. 계정 기본 배송지(사무실)를 유지하고 배송지
  스크립트를 부르지 않는다. 주문서 수령인·주소가 비어 있으면 needs_human.
- 상품은 원문링크의 `prdtNo` 로 연다. 상품명 검색 결과 페이지의 '품절' 은 근거가 아니다.
- 요청 옵션에 "일시품절" 이 표시되면 품절이다 → fail(out_of_stock).
- 계정별 쿠폰은 계정 탭 프로필마다 따로 본다(세션이 계정마다 분리돼 있다).
