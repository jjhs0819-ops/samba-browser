# 구매 에이전트 — 롯데온

공통 규칙([buyer_default.md](buyer_default.md))을 잇는다. 여기에는 이 소싱처만의 차이만 적는다.

## 이 소싱처만의 차이
- 요청 옵션에 "품절" 이 표시되면 품절이다 → fail(out_of_stock). "품절임박"(재고 적음)은 품절이 아니다.
- 롯데백화점 판매 상품만 산다(sources.yaml `required_seller`). 판매자가 다르면 품절이 아니라 '여기서 못 사는 상품' — 사람에게.
- 배송은 전부 고객 직배(`order_type: direct`, 2026-10-16 무신사와 같은 승인 흐름). 선물하기·까대기·샵백 경유는 쓰지 않는다.
- 직배 주문서의 새 배송지는 `lotteon_set_shipping`('변경' → '새 배송지 추가')이 넣고, 전화 칸은 **고객 번호를 절대 쓰지 않고** 앱이 키마스터 신원정보(사장님 CS 번호, 업무폰)로 채운 뒤 `lotteon_confirm_shipping` 이 주문서에서 이름·도로명+번호를 되읽어 확인한다(사용자 2026-10-16).
- 결제수단(사용자 2026-10-16): 할인 카드가 건마다 다르다 — 주문서 견적에서 **총액이 실제로 내려간** 수단(즉시할인 적용) 가운데 최저로 결제한다. 눌러도 금액이 안 내려가는 할인(회색 타일)은 인정하지 않는다. 카카오페이 머니 기본 1,000원 할인은 쓰지 않는다. 할인 수단이 없으면 **네이버페이 + 넥슨 현대카드**(무신사 현대카드는 무신사 전용 — 사용자 2026-10-22). 할인 줄이 네이버페이여도 결제창 카드는 넥슨 현대카드로 고정 — 결제 단계가 네이버페이 결제창(pay.naver.com) 안에서 등록 카드 글자를 읽어 그 카드를 고르고, 되읽어 선택이 확인돼야 키패드로 간다. 그 카드가 없거나 선택이 다르면 결제하지 않고 사람에게. 네이버페이가 허용 수단에 없어도 다른 수단으로 대신 사지 않는다.
- 원가 = 실제 결제 승인액(`paid_is_cost`). 카드 청구할인 계수를 곱하지 않고, 사용한 L.POINT 도 더하지 않는다.
- 계정별 쿠폰은 계정 탭 프로필마다 따로 본다.
